# 🏦 ATM Interface

A Java-based ATM Interface project that simulates basic banking and ATM operations through a console-based application.

## 📌 Project Description

This project is a simple ATM simulation developed using Java. It allows users to perform common banking operations such as checking account balance, depositing money, withdrawing money, and viewing transaction details.

The project demonstrates the use of **Object-Oriented Programming (OOP)** concepts, Java classes, methods, and user input handling.

## ✨ Features

- 🔐 Account management
- 💰 Check account balance
- 💵 Deposit money
- 💸 Withdraw money
- 📋 View transaction details
- 🏦 Bank and account management
- ⚠️ Handles invalid transactions
- 🔄 Menu-driven ATM interface
- 📊 Transaction tracking

## 🛠️ Technologies Used

- **Java**
- **Eclipse IDE**
- **Java Scanner**
- **Object-Oriented Programming (OOP)**
